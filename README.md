# 📞 PhoneBook-BST (C++)

A console-based PhoneBook Management System developed in C++ using fundamental data structures.

This project demonstrates the implementation of a Binary Search Tree (BST) and Stack for efficient contact management and organization.

---

## 🚀 Features

- ➕ Add new contacts
- 🔍 Search contacts by name
- 🗑️ Delete contacts
- 📋 Display contacts in sorted alphabetical order
- 🌳 Store contacts using Binary Search Tree (BST)
- 📚 Use Stack for managing traversal paths and operations

---

## 🛠️ Technologies Used

- C++
- Data Structures
- Binary Search Tree (BST)
- Stack
- Object-Oriented Programming (OOP)

## ⚙️ How It Works

Each contact is stored as a node in a Binary Search Tree.

The BST allows efficient operations such as inserting, searching, and deleting contacts.

The inorder traversal algorithm is used to display contacts in alphabetical order.

A Stack data structure is also used to manage traversal paths and support specific operations.
